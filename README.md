# 深夜二時のミケ（MIDNIGHT CALICO）

Unity制作 Day103：バイオハザード2風の固定カメラで、深夜の一軒家に隠れた三毛猫「ミケ」を捕まえる3Dゲーム（iPhone 横持ち操作対応）。

## どんなゲーム？
午前2時。三毛猫のミケが家じゅうを走り回っている。明日は動物病院の予約。
**朝6時（15分）までにミケを捕まえればクリア。**

- 舞台：平屋の一軒家（リビング／和室（居間）／廊下・玄関／キッチン／トイレ／脱衣所／浴室／寝室）
- バイオ2風：部屋ごとの**固定カメラ**がカットで切り替わる、**タンク操作**、懐中電灯、ECG付きアイテム画面、マップ、きらめくアイテム
- ミケのAI：見る・聞く（走ると足音でバレる）・背後からは気づきにくい・逃げて隠れる・家具を倒して暴れる・「運動会」
- 隠れ場所11か所（手が届く所／届かない所：ベッドの下・冷蔵庫の上・押入れの奥・洗濯機のすき間）
- 隠しアイテム：**猫じゃらし**（和室の箪笥）／**カリカリ**（キッチンの食器棚）／**おやつペースト**（寝室のナイトテーブル）／**またたび**（玄関の下駄箱）／**洗濯ネット**（脱衣所の洗濯カゴ）／**絆創膏**（洗面台）
- 暗がりでミケの**目が黄緑色に光る**。顔の向きで反射が変わり、部屋の照明を点けると控えめになる。懐中電灯ではさらに強く反射する

## 操作（iPhone 横持ちが基本）
| 操作 | iPhone 画面コントローラー | ゲームパッド（PS/Xbox/MFi） | キーボード |
|---|---|---|---|
| 移動 | 左側どこでも触った所がスティック。**少し倒す＝しのび足**、大きく倒す＝歩く | 左スティック | 矢印 / WASD |
| 走る（足音でミケが逃げる） | 「走るに切替」をタップ（ポーズ画面で長押し方式にも変更可） | B / RT | Shift / X |
| 調べる・捕まえる | 右下の大ボタン（対象名・目印が表示される） | A | E / Space |
| 装備アイテムを使う | 主ボタン左上の道具ボタン（装備名が出る） | X | Q |
| 懐中電灯 ON/OFF | ライトボタン | Y | F |
| アイテム画面 | 右上 ITEM | Select / View | TAB |
| ポーズ | 右上 Ⅱ | Start / Menu | Esc |

- iPhone・ゲームパッドは「スティックを倒した方向に進む」操作。ポーズ画面の「操作切替」でバイオ2式のタンク操作（↑前進・←→旋回）に変えられる
- ノッチ・ホームバーを避けて配置（Safe Area 対応）、マルチタッチで「歩きながら調べる」もOK
- メッセージは画面のどこをタップしても送れる
- iOSネイティブビルドでは、捕まえた時・ひっかかれた時に振動

## リアル表現
- 木目・畳・タイル・布・壁紙・猫の毛に**凹凸（法線マップ）**→ 懐中電灯を当てると質感が浮き出る
- 懐中電灯は**反射板の輪とホットスポット**のある光の形＋**光の中に舞うほこり**
- 家具の下・壁ぎわに**接地の陰**、天井の廻り縁・幅木・スイッチ・コンセント・額縁・カレンダーなど生活感
- **フィルム調の画面**（影は青緑・明かりは暖色・粒子ノイズ・わずかな色収差）※Built-in パイプライン時
- ミケ：毛のふくらみ、呼吸、片耳ピクッ、イカ耳、しっぽの先のピクピク、首かしげ、暗いと丸く・ライトで細くなる瞳孔、目のハイライト、足もとの影

## 攻略のヒント
- 手が届かない場所に入られたら、**好きなもので誘い出す**（おやつペースト・猫じゃらし・カリカリ）
- カリカリ・またたびは**置いて離れる**→食べている／転がっている間は確実に捕まえられる
- 洗濯ネットを持っていると捕獲成功率が大きく上がる
- 失敗するとひっかかれる。Danger になると足が遅くなる（絆創膏で回復）

## Unityで開く
1. このリポジトリをダウンロードまたは clone する
2. Unity Hub の「追加 → ディスクから加える」で、このフォルダを選ぶ
3. **Unity 6000.3.26f1 / Built-in Render Pipeline** で開く（パッケージは `Packages` の固定設定を使用）
4. `Assets/MidnightCalico/Scenes/MidnightCalico.unity` を開いて ▶ 再生。再セットアップが必要なら **MidnightCalico > ① セットアップ**

`Assets`（`.meta`・日本語フォントとライセンスを含む）・`Packages`・`ProjectSettings` を保存しています。キャッシュ・ログ・個人設定・ZIP・ビルド出力はアップロードしません。`Library` はUnityで開くと再生成されます。

プレイ: https://titan11111.github.io/unity-day103-midnight-calico/

このリポジトリの `main` はUnityの編集用データです。ブラウザで遊ぶファイルは `gh-pages` にあります。公開時はWeb出力一式のSHA-256と本番配信ファイルを照合します。最新リリースの `release.json` に変更ID・ソースコミット・配信ファイル一覧を記録します。iPhone/Android実機での操作感は未検証です。

外部の3Dモデル・音声ファイルは使わず、家・家具・猫・主人公・テクスチャ・効果音はすべてスクリプトで生成しています。

## WebGL（GitHub Pages）で公開 → iPhone の Safari で遊ぶ
1. メニュー **MidnightCalico > ③ WebGLビルド** → `Builds/WebGL` に出力（圧縮なし・`.nojekyll` 付き）
   - `index.html` は自動で iPhone 向けに調整される：全画面・ピンチズーム無効・長押しメニュー無効・「モバイル非対応」バナー削除・縦持ちだと「横向きにしてね」表示
   - Safari の共有 →「ホーム画面に追加」で開くと、アドレスバーなしの全画面で遊べる
2. `Builds/WebGL` の中身（`index.html` / `Build/` / `TemplateData/` / `.nojekyll`）を `gh-pages` ブランチの直下に置いて push
3. GitHub の Settings > Pages は `gh-pages` / `(root)`。プレイURLは https://titan11111.github.io/unity-day103-midnight-calico/

## iPhone アプリとして実機に入れる（任意）
1. Unity Hub で「iOS Build Support」を追加
2. メニュー **MidnightCalico > ④ iOSビルド** → `Builds/iOS` の Xcode プロジェクトを開いて実機へ（横画面固定・ステータスバー非表示は設定済み）

## ファイル構成
```
Assets/MidnightCalico/
  Scripts/Core    GameManager（進行）, GameInput（キー・タッチ）, Audio（効果音合成）, Mat/Tex（質感生成）
  Scripts/World   HouseBuilder（間取り・家具・照明・カメラ位置・猫の通り道）, World（部屋/隠れ場所/小物）
  Scripts/Cat     CatAI（ミケの頭脳）, CatModel（ミケの体とアニメ）
  Scripts/Player  PlayerController（主人公ナツキ）, FixedCameraSystem（固定カメラ）, Inventory
  Scripts/UI      UIManager（タイトル/導入/メッセージ/アイテム画面/マップ/エンディング/タッチ操作）
  Editor          MidnightCalicoSetup（自動セットアップ・WebGLビルド）
  Resources/Fonts 日本語フォント（Noto Sans/Serif CJK JP をゲーム内の文字だけに絞ったもの・SIL OFL）
```

## 2026-10-30 操作改善
- 左スティックの短いストロークで低速歩行〜通常歩行。走行は右のタップ切替が標準。キーボード・ゲームパッドの長押し走行は維持。
- ポーズ画面の下段で、走行方式／サイズ85・100・115%／位置3段階／濃さ3段階／スティック中心追従の有無を保存できます。
- 移動と各ボタンは指IDを独立管理。指離し・領域外・ポーズ・アイテム画面・フォーカス喪失時に入力を解除。
- カメラ切替時は入力方向を維持し、30度を超える倒し直しで新しいカメラ基準へ移行。境界に0.12mのカメラ切替猶予。
- 調べる対象と照明スイッチを距離・向きで比較し、選択中の対象を少し優先。対象名と目印を表示し、タッチ開始時の対象を固定。
- 猫へ手を伸ばすときは最大18度だけ向きを補助。捕獲確率は変更していません。
- 変更IDはAssets・Packagesの内容をハッシュ化し、未コミット変更も区別します。生成ファイル自身は除外。
